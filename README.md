## Projects:

### 1. [Sentiment Analysis End-to-End Deployment](./Sentiment%20Analysis%20End-to-End%20Deployment)
An end-to-end ML model deployment pipeline for a sentiment analysis model on Azure Kubernetes Service (AKS).

**Key Technologies:**
- FastAPI for ML model serving
- Kubernetes for orchestration and scaling
- Docker for containerization
- Redis for caching and performance optimization
- CI/CD pipeline implementation
- Hugging Face Transformers (DistilBERT)

**Features:**
- RESTful API endpoints with input validation
- Containerized deployment with Dockerfile
- Kubernetes configuration for production environments
- Automated testing with pytest
- Infrastructure as code for cloud deployment
- Monitoring and health check endpoints

### 2. [Flight Delay Prediction](./Flight%20Delay%20Prediction)
A machine learning project applying advanced ML techniques to predict flight delays using large-scale historical data.

**Key Technologies:**
- PySpark for distributed data processing
- MLFlow for experiment tracking and model management
- Time-series cross-validation methodology
- Advanced feature engineering
- XGBoost, Random Forest, and Neural Network models

**Technical Highlights:** 
- Developed ML pipeline handling 12M+ records
- Implemented custom feature engineering pipeline
- Addressed data leakage challenges in time-series context
- Applied hyperparameter tuning for model optimization
- Achieved 77.2% F1 score on held-out test data

### 3. [Personal Report AI Agent](./personal_report_ai)
An orchestrated AI agent system built with LangGraph that demonstrates advanced NLP implementation and integrations.

**Key Technologies:**
- LangGraph for agent orchestration
- FastAPI for backend services
- Ollama with Phi-4 model for inference
- External API integrations (news, weather, jobs)
- Containerization with Docker
- Kubernetes deployment plans

**Features:**
- Intent detection and classification
- Multi-node agent architecture
- Directed graph workflow for flexible agent behavior
- External API integrations
- Production deployment capabilities

### 4. [Social Media Influencer Analysis](./Social%20Median%20Influencer)
Data analysis project applying statistical methods to understand content engagement patterns across social platforms.

**Analysis Techniques:**
- Correlation analysis and statistical significance testing
- Feature engineering and feature importance
- Data normalization (Box-Cox transformation)
- Exploratory data visualization
- Large dataset processing (6000+ records)

**Key Insights:**
- Identified platform-specific engagement patterns
- Quantified correlation between content features and popularity metrics
- Developed category-based analysis framework
- Analyzed temporal patterns in content creation and engagement
